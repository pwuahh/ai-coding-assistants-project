# Requirements and evidence checklist

Source: the assignment document supplied by the requester, `project-software-development-2026.md`. This checklist summarizes its assessment requirements; it does not assert that those requirements have been met.

## Presentation — 50%

- [ ] **Accuracy and depth (20%)**: relevant current event, credible sources, accurate explanation and appropriate depth.
- [ ] **Clarity and creativity (15%)**: engaging delivery and actual video duration between 2:30 and 3:00.
- [ ] **Structure and flow (10%)**: clear introduction, logically ordered body, and conclusion.
- [ ] **Technical quality (5%)**: clear audio/video, suitable pacing, and distributed speaking contributions.
- [ ] Students provide the narration; no AI-generated voices.
- [ ] The final video is public on YouTube and its verified URL appears in the README.

## GitHub collaboration — 50%

- [ ] **Repository and README (5%)**: project title, topic summary, all member names and student numbers, roles, public video URL, and organized materials.
- [ ] **Commits (10%)**: meaningful, descriptive contributions from every team member over time.
- [ ] **Branches (10%)**: appropriately named task branches used before merging into `main`.
- [ ] **Issues (10%)**: clear task descriptions, confirmed assignees, appropriate labels, and resolution links.
- [ ] **Pull requests and review (10%)**: changes described, real teammates review/comment, feedback addressed, and work merged through PRs.
- [ ] **Discussions (5%)**: substantive participation from all members on GitHub Discussions, including decisions and feedback.

## Materials in the repository

- [ ] Research notes or draft write-up.
- [ ] Presentation script or outline.
- [ ] PowerPoint slides and any other visuals used.
- [ ] Media assets and credits; observe GitHub file-size limits for recordings.
- [ ] Final public YouTube URL in the README.
- [ ] Actual collaboration evidence: issues, commits, branches, PRs, reviews, and discussions.

## Final verification

- [ ] All placeholder values replaced with confirmed information.
- [ ] Every substantive factual claim has an appropriate source.
- [ ] A real timed rehearsal and final playback have been performed.
- [ ] Public repository and video are accessible while signed out.
- [ ] Final submission includes both URLs.

No checklist item should be marked complete solely because an AI generated a draft or proposed a task. A grade is determined by the instructor; this checklist cannot guarantee 100%.
