
# The Emergence of AI Code Assistants

**Course:** CEP146 - Essential Tooling for Programmers  
**Project:** Software Development Current Event

## Information About the Project

We investigated how artificial intelligence affects programming, specifically looking at GitHub Copilot, a tool that helps developers write code, find errors, and work on projects more efficiently.

In addition, we covered some of the downsides of using AI, such as receiving incorrect information and becoming too dependent on AI without fully understanding the code.
